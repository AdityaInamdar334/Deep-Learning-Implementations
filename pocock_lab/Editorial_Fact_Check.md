# Editorial fact-check · November 10, 2026
- **20 million for one file:** Incorrect attribution. The September Alibaba Cloud community article is a secondary collection-level report. On the check date skills.sh showed 32.4M collection installs, 1.1M for grilling and 1.5M for grill-me. Exact historical totals require dated first-party records. Install events cannot establish unique users. https://skills.sh/mattpocock/skills
- **Twelve lines:** Verified for v1.1.0. In v1.3.2 the same path has 30 lines. Its wrapper is a separate seven-line file. The old version asks one question at a time, the newer one asks independent questions together. See audit-output.txt and the pinned links in the article.
- **16, 27, 53 skills:** The v1.0.0 manifest lists 17. At v1.3.2 the manifest lists 27 and the skills tree contains 38 skill files. The 53-module secondary count has no established matching denominator in this audit. A directory listing includes historical names.
- **Stars:** GitHub displayed 319.9k when checked. Historical July/September/October estimates are unnecessary for the argument and were not independently reconstructed.
- **Four failure modes:** Verified as README rationale. Engineering and productivity are the promoted directories in the tagged manifest. The four are not four directory names.
- **Commands and handoff:** The v1.3.2 manifest includes to-spec, to-tickets and writing-for-agents. to-prd, to-issues and writing-great-skills are historical. ask-matt belongs to engineering. handoff writes to an OS temporary directory. implement includes review and a commit.
- **Exactly three questions:** Three topics. Triage labels are conditional; single-context domain layout is the default. Linear is documented as a custom workflow. Setup actually writes repo-specific files.
- **Two install paths:** The README distinguishes a plugin and editable installation through skills.sh, with host-specific paths and update behavior. skills.sh versus manually copying is the wrong distinction here.
- **October changes:** The v1.3.0 and v1.3.2 tag dates are October 4 and October 29. The changelog confirms glossary renaming and whole-spec implementation promotion in 1.3.0 and mutation verification, ask-matt and review changes in 1.3.2. chief-of-staff is in-progress in the latter tag.
- **12 vs 689:** Comparing an interview primitive to a skill-authoring guide conflates functions. No stable version or counting method for the 689-line claim was supplied; the comparison was dropped.
- **Token savings and entropy:** The author argues for clearer vocabulary and frequent design work. The examples supply no effect-size estimate for compute, defect rates, or entropy. A glossary phrase need not be one tokenizer token.
- **Pocock’s background:** Orosz’s interview identifies Total TypeScript, reports over $2.5M in course sales, and describes Vercel work. It is attribution for the revenue figure, not an audited statement. Exact corporate titles, newsletter size and independent financial verification were unnecessary to the article. https://newsletter.pragmaticengineer.com/p/ai-skills-with-matt-pocock
- **Thoughtworks:** Trial, November 4, 2026. Its recommendation to evaluate individual skills is an attributed practitioner assessment. https://www.thoughtworks.com/radar/tools/mattpocock-skills
- **Bus factor, TypeScript bias and monthly pruning:** A maintainer-centered editorial voice is visible. Git authorship alone does not establish release authority or a numerical bus factor. Language fit and pruning cadence are team-dependent judgments.
- **Source list:** The draft cited the same Tencent URL under two titles. A site homepage and a plugin citation without an exact destination do not substantiate the corresponding details. The article uses the tagged originals and named primary coverage.
