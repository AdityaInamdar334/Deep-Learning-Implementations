# Benchmark methodology and limitations

## Question

Can bounded analysis operations and independent verification prevent *known scripted methodological errors* in a small electrophysiology workflow, and what runtime overhead do safeguards add?

## Data

Five seeds (0 through 4) from `make_synthetic_recording()`. Each recording has 12 units and 30,000 ms of synthetic event times. A simulated cue occupies the middle third. Four units share jittered events; some have additional cue-associated spikes. No raw brain recording is used.

## Experimental conditions

- `bounded`: explicit cue/no-cue windows, STTC, 19 circular-shift surrogate draws per pair, BH correction, 50 ms binned leave-one-out Pearson coupling proxy, PCA, audit log, provenance and caveats.
- `no_verification`: same STTC and correct windows but zero surrogate draws, no p or q values.
- `improvised`: first half versus second half used without clarification, binned Pearson substituted for STTC, includes self in population coupling, 150 ms bins, no provenance.
- `silent_downsample`: same correct conditions, STTC and verification as bounded, but uses 200 ms rather than 50 ms bins for the population coupling proxy and PCA.

The improvised policy is **deliberately flawed code**, not output generated by a real model. Therefore the pass-rate differences are partly constructed by experimental design.

## Independent evaluator

The 14 assertions cover explicit conditions, clarification, preserved units and spike counts, correct pair count, correct method name and STTC value, present surrogate p and BH-adjusted q values, original bin width, leave-one-out coupling, PCA reference, and provenance/caveats. They do not match the original SpikeLab paper's rubric.

Reference checks are computed in `evaluator.py`, separate from the policy's reported summary, but some reference primitives come from the same `methods.py`. A production evaluator should use an independently validated reference implementation, different code dependencies, broader edge-case coverage, and a human review protocol.

## Timing

Elapsed seconds measured by `time.perf_counter()` include only local computation and Python overhead. Neither network latency nor billed tokens nor LLM generation time is measured. Small datasets produce very short durations, especially for the flawed policies. The reported benchmark runtimes are not cloud or real-world science throughput.

## Statistical caveats

- STTC returns undefined (`NaN`) when either spike train is empty. Never silently replace with zero.
- Circularly shifting spikes can preserve within-unit spacing but does not guarantee a valid null in nonstationary cue-modulated activity.
- With 19 surrogate draws, the smallest possible Monte Carlo p-value is `1 / 20 = 0.05`. A threshold of 0.05 provides little resolution. Do not interpret absence of significant edges as absence of relationships.
- Benjamini-Hochberg assumes appropriate dependence conditions, and many pairwise neural signals are strongly dependent. More robust null schemes may be needed.
- The coupling statistic is a Pearson binned-rate proxy, not a validated replacement for the original stPR population-coupling estimator.
- PCA explained variance is descriptive; it does not establish discrete brain states or fit a temporal state-space model.
- Every test dataset here is synthesized; empirical biological generalization is unmeasured.
